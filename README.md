# EBook Reader You

A native Android full-suite book and comic reader with Material You dynamic colors and an optional true-black AMOLED mode.

## Formats

- EPUB
- PDF
- TXT
- CBZ
- CBR

## Features

- Multi-file and folder import through Android's Storage Access Framework
- Searchable library with recent, favorite, book, and comic filters
- Reading progress and per-book resume positions
- EPUB chapter navigation with embedded styling and images
- PDF page rendering with pinch zoom
- CBZ and CBR page extraction with right-to-left manga mode
- TXT typography, line spacing, text-to-speech, and reading themes
- Dynamic Material You accent colors on Android 12+
- Optional AMOLED black surfaces while retaining dynamic accents
- Immersive reading, brightness control, orientation control, bookmarks, and sharing
- Safe archive extraction limits and path traversal protection

The latest installable APK is attached to the repository release and every workflow run.
